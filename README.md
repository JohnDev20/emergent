# Casa em Dia

Gerenciador Android de despesas pessoais e familiares. Os dados ficam no aparelho.

## Primeira versão

Cadastre descrição, valor, data, categoria, pessoa que pagou e tipo de gasto. O resumo mensal soma os dois tipos uma única vez. Os filtros por pagador e tipo afetam o subtotal dos lançamentos. Toque em um gasto para editar ou excluir.

Android 8 ou superior. Pacote: `com.johndev.casaemdia`. A compilação de teste está configurada no GitHub Actions e no Codemagic.
